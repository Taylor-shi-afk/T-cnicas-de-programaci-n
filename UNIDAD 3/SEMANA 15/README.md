# 📝 Aplicación GUI de Lista de Tareas

## 📌 Descripción del Proyecto
Esta es una aplicación de escritorio sencilla y funcional desarrollada en Python utilizando la biblioteca gráfica `Tkinter`. Su objetivo principal es permitir a los usuarios gestionar una lista de tareas pendientes, proporcionando una interfaz intuitiva para añadir, completar y eliminar actividades diarias.

El proyecto está diseñado cumpliendo con principios de diseño de interfaces gráficas de usuario (GUI) y manejo de eventos.

## ✨ Características Principales
* **Añadir Tareas:** Interfaz de entrada de texto que permite añadir tareas usando un botón o presionando la tecla `Enter`.
* **Marcar como Completada:** Cambio de estado visual para identificar las tareas finalizadas. Se puede activar mediante un botón en la interfaz o haciendo **doble clic** directamente sobre la tarea en la lista.
* **Eliminar Tareas:** Remoción sencilla de las tareas seleccionadas mediante un botón dedicado.
* **Manejo de Eventos Avanzado:** Respuestas fluidas a eventos del teclado y del ratón para mejorar la experiencia del usuario (UX).

## 🛠️ Tecnologías y Requisitos
* **Lenguaje:** Python 3.x
* **Biblioteca Gráfica:** `tkinter` (Incluida por defecto en la instalación estándar de Python).
* **Entorno Recomendado:** PyCharm, VS Code o cualquier IDE compatible con Python.

## 🚀 Instrucciones de Instalación y Uso
1. **Descargar el código:** Asegúrate de tener el archivo fuente (por ejemplo, `lista_tareas.py`) en tu máquina local.
2. **Abrir en el IDE:** Abre el archivo utilizando tu entorno de desarrollo (como PyCharm).
3. **Ejecutar la aplicación:** Ejecuta el script. Se abrirá la ventana principal del "Gestor de Lista de Tareas".
4. **Interacción:**
   - Escribe una tarea en el campo de texto y presiona `Enter` para agregarla.
   - Selecciona una tarea y presiona "Marcar como Completada" (o haz doble clic sobre ella).
   - Selecciona una tarea que desees borrar y presiona "Eliminar Tarea".

## 📁 Estructura del Código
El código está organizado lógicamente en dos secciones principales:
1. **Lógica de la Aplicación y Eventos:** Funciones dedicadas a manipular los datos de la lista y responder a las interacciones del usuario (`agregar_tarea`, `marcar_completada`, `eliminar_tarea`).
2. **Configuración de la Interfaz (GUI):** Construcción y posicionamiento de los *widgets* (marcos, botones, campos de entrada, listas y barras de desplazamiento).
