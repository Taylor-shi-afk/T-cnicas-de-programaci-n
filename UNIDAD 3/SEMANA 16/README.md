# Gestor de Tareas (GUI con Tkinter)

Una aplicación de escritorio ligera e intuitiva desarrollada en Python utilizando la biblioteca `tkinter`. Este programa permite a los usuarios gestionar una lista de tareas pendientes de forma rápida, utilizando tanto una interfaz gráfica con botones como atajos de teclado para una mayor eficiencia.
---
## 🚀 Características Principales

* **Interfaz Gráfica Sencilla:** Campo de entrada, botones de acción rápida y una lista visible para administrar tus tareas del día a día.
* **Soporte de Atajos de Teclado:** Diseñado para ser utilizado sin necesidad de tocar el ratón.
* **Feedback Visual:** Las tareas completadas se marcan claramente con un icono `✅ (Completada)` y cambian a color gris, diferenciándolas visualmente de las tareas pendientes.
* **Prevención de Errores:** Incluye control de excepciones para evitar que el programa se cierre si intentas interactuar (completar o eliminar) sin haber seleccionado una tarea.
---
## 📋 Requisitos Previos

Para ejecutar este programa, solo necesitas tener instalado:
* **Python 3.x**
* La biblioteca **Tkinter** (Normalmente viene preinstalada con la instalación estándar de Python en Windows y macOS. En algunas distribuciones de Linux, puede requerir instalación manual mediante `sudo apt-get install python3-tk`).

## ⚙️ Cómo Ejecutar el Programa

1. Guarda el código fuente en un archivo con la extensión `.py`, por ejemplo: `gestor_tareas.py`.
2. Abre tu terminal o línea de comandos.
3. Navega hasta la carpeta donde guardaste el archivo.
